# Парсер вакансий с HH.ru

Программа для поиска, сохранения и фильтрации вакансий с сайта hh.ru.

## Функциональность

- Поиск вакансий по ключевым словам на hh.ru
- Сохранение вакансий в JSON и CSV форматах
- Фильтрация вакансий по ключевым словам, зарплате, работодателю
- Сортировка вакансий по зарплате
- Удаление и очистка сохраненных вакансий
- Экспорт результатов в текстовый файл

## Структура проекта
~~~PythonProject3/
├── src/ # Исходный код
│ ├── init.py
│ ├── api.py # Работа с API hh.ru
│ ├── vacancy.py # Класс Vacancy
│ ├── storage.py # Хранилища данных (JSON, CSV)
│ └── utils.py # Вспомогательные функции
├── tests/ # Тесты
│ ├── test_vacancy_app.py
│ └── test_extended.py
├── data/ # Данные (создается автоматически)
│ ├── vacancies.json # JSON файл с вакансиями
│ └── vacancies.csv # CSV файл с вакансиями
├── main.py # Основной файл для запуска
├── requirements.txt # Зависимости
├── pyproject.toml # Конфигурация проекта
└── README.md # Этот файл
~~~


## Установка

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
cd PythonProject3
```
Использование
```
Запустите python main.py
```

Выберите действие из меню:

1 - Поиск вакансий

2 - Показать сохраненные вакансии

3 - Фильтрация сохраненных вакансий

4 - Удалить вакансию

5 - Очистить сохраненные вакансии

6 - Экспорт в CSV

7 - Выход

Тестирование
Для запуска тестов:

```
pytest tests/ --cov=src --cov-report=term-missing
```
Требования
Python 3.8+

requests>=2.31.0
